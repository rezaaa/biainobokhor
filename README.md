# Biainobokhor

> 🍔 Generate SnapFood reports and create shareable images with custom styling.

**Biainobokhor** (بیا اینو بخور) is an open-source web app built with **Svelte** that lets users generate detailed reports from their SnapFood account and turn those reports into **customizable images** ready to share.

The app works entirely in the browser, does **not store tokens**, and is designed with privacy in mind.

👉 Live demo: https://www.biainobokhor.ir

---

## ✨ Features

- 📊 **SnapFood account report**
  - Generate a detailed summary of your SnapFood activity using your access token.

- 🖼 **Create shareable images**
  - Convert reports into images suitable for sharing on social media.
  - Customize visuals such as layout, colors, and presentation.

- 🔐 **Privacy-first**
  - Tokens are processed locally in the browser.
  - No data is stored or sent to a backend server.

- ⚡ **Fast & lightweight**
  - Built with **Svelte** for high performance and small bundle size.

## 🚀 Getting Started

### Prerequisites

- Node.js **16+**

### Installation

```bash
git clone https://github.com/rezaaa/biainobokhor.git
cd biainobokhor
npm install
```

---

## 🛠 Development

### Run locally

```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

### Build for production

```bash
npm run build
```

Production files will be generated in the `dist/` directory.

## 🔒 Security & Privacy Notes

This project requires users to paste a private SnapFood token.

**No tokens or user data are stored or logged.**  
All processing happens locally in the browser.

For safety, only use temporary tokens and revoke them when finished.
